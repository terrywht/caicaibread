鲁邦种使用与保存速查卡

3 年成熟鲁邦种 · 野性 T65 · 1:1:1 喂养 · 用于欧包
判据优先看状态，不看时间，也不看固定倍数

一、最佳使用时期：六项速判

指标峰值状态过峰状态
顶部形态 圆拱穹顶、表面绷紧有张力 先转平，再中间下凹、起皱
体积 涨到 2–2.5 倍（相对喂养后起始线） 开始回落
内部结构 蜂窝细密、拉丝不断 气泡粗大、破泡、组织塌软
气味 酸香圆润，带麦香 醋酸味变冲、刺鼻、发涩
触感 轻敲罐壁，表面缓慢微陷 敲下去塌得快、无回弹
浮水测试 一小勺丢入室温清水，浮起 沉底
核心原则：峰值不是"涨到某个倍数"，而是高度停止上涨的那一刻。倍数因种、粉、温度而异，拐点才是通用信号。

二、峰值到底怎么定——皮筋法

  1. 喂养拌匀后立刻在罐壁套橡皮筋或画线，标出起始高度（这一步不能省）。
  2. 之后每 30–60 分钟记录一次高度（拍照或画线）。
  3. 高度不再上升 + 顶部仍为圆拱 = 峰值已到。
  4. 一旦顶部转平或出现中心凹陷，窗口即结束，不要再等。
容器只装 1/4–1/3，留 2–3 倍膨胀空间。装满罐会顶到瓶颈、被挤压塌陷，且看不到回落信号。
浮水测试的六个常见假阴性：舀取时压扁了种 / 取到了失气的表层 / 水太少碰到杯壁 / 用了冰水致气体收缩 / 样品太小 / 没等满 5–10 秒。

三、做欧包该在哪个点取用

流派取用点理由
主流做法 峰值（穹顶绷紧、即将回落） 酵母活性最强、面筋未被酸侵蚀，入炉膨胀与割口"耳朵"最好
另一流派 峰值前 30–60 分钟（约 80–90% 到峰） 面团内仍有食物可支撑长时间低温一发，且酸度最低
不建议 已经回落之后 面筋被酸水解，成品长不高、摊平、组织紧实、酸味重
欧包接种量低、一发时间长、没有商业酵母兜底，种的状态直接决定成败，比做吐司更挑时机。经验共识，非定量结论。

四、用 T65 做种 / 做包的注意点

指标T65 典型值影响
灰分约 0.62–0.75%（高于 T55）矿物质多、酶活活跃 → 发酵偏快、风味更足，峰值窗口来得早，观察要更勤
蛋白约 10.5–11.5%筋度中等 → 单用做欧包面筋支撑偏弱，建议搭一部分高筋粉
灰分高的粉缓冲能力强，同样发酵时间下酸感可能更圆润而非更冲（推测，无该粉实测数据）。具体以包装配料表与营养成分表为准。

五、平时保存：三种方式怎么选

方式操作可存取出后状态
① 用完直接冷藏 剩余种盖紧直接进 4℃ 冰箱，不喂 约 2–3 周（活性缓慢下降） 酸度高、保气差、活性低
② 喂养后直接冷藏
推荐		 按 1:2:2 或 1:3:3 喂饱，室温放 30–60 分钟让发酵启动，再冷藏 约 5–7 天 状态较好，容错高
③ 喂养后涨到 2 倍再冷藏 室温发到峰值，再整罐冷藏 约 3–7 天 峰值状态被"冻结"，理论最好
原理：冷藏是把代谢速率降到约 10%，不是停止。不喂就冷藏 → 食物耗尽、酸度持续积累，久了会变成"酸弱"状态（面筋被酸水解、保气差）。喂饱再冷藏 → 带着充足食物进冰箱，出冰箱时状态好。
方式③ 的前提是你正好在峰值那一刻在场，否则要么没到峰、要么已经过峰，实操上不如方式②稳。
使用频率对应：每隔 1–3 天做一次 → 方式①短周期即可；每周 1–2 次 → 方式②；超过两周不用 → 方式②并每周取出补喂一次。

六、冷藏取出后能直接用吗

冷藏时长能否直接用于欧包处理
少于 24 小时
（含隔夜冷藏喂养）		 可以 回温 30–60 分钟后直接用
1–3 天 不建议 回温 30–60 分钟，先喂一次（1:1:1 或 1:2:2），到峰再用
超过 3 天 不可 先做一次"薄喂唤醒"（1:5:5），发起来后倒掉大部分，再正式喂一次到峰
不能直接用的三条理由：① 冷藏种 4–6℃，直接揉进面团会显著拉低出缸面温（欧包目标 22–24℃）；② 低温让酵母进入待机，产气弱，一发会明显偏慢、入炉膨胀差；③ 冷藏期间酸度仍在积累，直接用会让成品更酸、面筋更弱。
唯一例外——隔夜冷藏喂养法：按 1:5:5 喂完，室温放 1 小时启动，再冷藏 10–14 小时，第二天早上取出时正好在冷藏中涨到峰。这是刻意用冷藏来"排程到峰"的做法，此时回温 30 分钟即可直接用。属经验做法，需按自家冰箱温度自行校准。

七、常见误区

误区正解
"涨到 2 倍就是峰值"倍数因种而异，要看停止上涨的拐点
"冷藏了一周，拿出来直接用"超过 3 天必须先补喂，否则一发拖长、入炉膨胀差
"冷藏期间发酵停了"只是变慢，酸度仍在积累，时间越久越酸越弱
"喂养比例随便，1:1:1 最省事"保存期用 1:2:2 / 1:3:3 容错更大、峰值窗口更宽、酸度更低
"沉底就是种坏了"沉底只说明这一轮保气不足，补喂一轮到峰即可恢复
"罐子能装多少装多少"只装 1/4–1/3，留 2–3 倍膨胀空间
面包发酵受温度、湿度、面粉、酵母等多种因素影响，本卡内容基于经典烘焙理论与常见经验，仅供参考。
