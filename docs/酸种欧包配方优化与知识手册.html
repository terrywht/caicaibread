四、制作流程

阶段 0 · 养种（提前 8–12 小时）

  • 鲁邦种按 1:5:5 或 1:4:4 喂一次
  • 在涨到约 2 倍、尚未回落时使用（上次用 2.5 倍偏熟，酸度高、面筋已开始弱化）

阶段 1 · 水合（关键改动）

  • 粉类 + 全部水 + 全部盐混合成团，不见干粉即可
  • 冷藏 4℃ 静置 2–4 小时，也可室温 1 小时
  • 盐从"后期加"改为"水合时就加"——抑制蛋白酶，保护长水合中的面筋

五、"85% 水合配 13%+ 粉"是怎么来的

它不是硬性规定，而是从三组数据推导出的经验法则。

5.1 推导链条

① 蛋白含量 ↔ 吸水率正相关

面粉吸水率主要来自破损淀粉吸水 + 蛋白质与戊聚糖的水合能力。蛋白越高，能结合的游离水越多。

蛋白含量典型吸水率适合水合区间
8–10%（弱筋）50–55%≤55%，多了成糊
11–12%（中高筋）60–70%65–75%
12–13.5%（面包粉）65–78%65–78%
13–15%（强筋/特高筋）70–95%75–85%+

② 高水合需要面筋网络"扛得住"

水多的本质是面团更软、延展性更强、气孔更大。但面团必须同时具备足够的强度（tenacity），否则气孔壁撑不住就会合并、塌陷。85% 水合意味着面筋要在很稀的基质里维持住气孔。

③ 行业实践印证

Bread Flour（12–13.5%）常规水合区间 65–78%；要推到 80%+，实践上要么改用更高蛋白（Manitoba 类）的粉，要么用 coil fold、延长冷藏等手法补强。

更准确的表述：想稳定地在 85% 水合下得到开放组织，面粉的 W 值（面筋强度）比蛋白百分比更关键——大致对应 W 280–350（强筋级），蛋白一般落在 13% 以上。

5.2 四种反例：它不适用于所有面包

反例原因
法棍 / T65 乡村包T55/T65 蛋白仅约 10.5%，水合也能到 70–75%，靠的是灰分高、延展性好（P/L 偏低）+ 长时间发酵，不是靠蛋白
全麦 / 黑麦面包麸皮和戊聚糖吸水性极强，表面吸水率很高但成筋能力弱。70% 全麦手感相当于 60% 白面。这类面包要降低水合或靠酸性环境稳结构
可颂 / 丹麦蛋白仅 11–12%，水合 50–55%。这里故意要弱面筋，避免回缩、让层次展开
馒头包子中筋粉 50–55% 水合，不在这个语境

5.3 更准确的判断框架

水合上限 ≈ f（面筋强度 W、延展性 P/L、工艺强度、目标组织）

变量提高水合上限的加分项
面筋强度W 值高（280+）、蛋白 13%+
延展性平衡P/L 约 0.5（太高回缩，太低会摊）
工艺强度更多次折叠、coil fold、lamination、低温长发酵
目标组织要大孔开放组织可推高；要均匀细腻就别推高

你的具体情况：纯芯 11.9% + 10% 黑麦，有效成筋蛋白约 10.7%，W 值大致落在中弱区间（W 180–240 附近）——这就是 85% 对这套粉偏高的原因。要么换更强的粉，要么把水降到 78–80%，二选一。

六、面粉推荐

先说明：面粉没有"最好"，只有"最匹配你的目标"。同品牌不同批次也有差异，最终以包装袋营养成分表为准。

6.1 第一推荐：高蛋白吐司粉 / 特高筋粉作为基粉

面粉蛋白灰分推荐理由
王后 日式吐司粉13.8–14.1%0.42%与纯芯同为日系精制路线，但蛋白高一整档，吸水率可达 80%。风味表现最接近你现在的组合，替换最顺
昭和 先锋（特高筋粉）14.0%0.42%日系特高筋代表，面筋强、耐力好，搭配黑麦/全麦时最常用。想上 85%+ 水合的首选
金像 面包粉13.7%—性价比高、国内易得，面筋强、弹性好，适合日常练习推高水合
王后 柔风吐司粉13.2%0.42–0.48%蛋白适中、延展性好、操作宽容度高，往高水合过渡的稳妥选择

6.2 第二推荐：T 系列路线（麦香更足）

面粉蛋白灰分说明
王后 T6510.5%0.65%法式乡村包经典粉。蛋白低但延展好、麦香足。用 T65 时水合建议 72–75%，不要硬推 85%
日清 百合花（法国粉）10.7%0.45%法棍/乡村包常用，风味比 T65 更干净

黑麦部分：建议用 T85（细磨黑麦）走乡村包路线，风味清晰、对结构干扰小；T130 颗粒粗，10% 用量下影响不大但吸水更强。

6.3 推荐依据

  1. 蛋白含量：要 13%+ 支撑高水合，13.2–14% 是黄金区间；低于 13% 易塌陷，高于 14.5% 延展性变差、整形困难
  2. 灰分：0.37–0.45% 是精制路线（组织细腻、风味干净）；要麦香就走 0.55–0.65%（T55/T65），代价是水合上限下降
  3. 吸水率实测：王后日式吐司粉可达 80%，金像吐司粉约 75%，山茶花/金像普通高粉约 72%。吸水率越高，越能承接高水合
  4. 产地工艺：日系粉制粉精度高、出筋快、弹性好、组织细腻；国产粉更耐搅拌、膨胀性好、性价比高
  5. 为什么不给唯一解：蛋白含量只说明"有多少蛋白"，不说明"蛋白质量如何"。同样标 13% 的两款粉，在高水合酸种里表现可能完全不同——因为 W 值和 P/L 平衡不同

实操建议：先用现有纯芯按方案 A（80% 水合）跑 2–3 炉，把发酵节奏和整形手法稳住；然后只换粉、不动其他参数再跑一炉（先试王后日式吐司粉），对比组织差异。这样能把"粉的影响"单独隔离出来，比一次性改三个变量高效得多。

七、加入干性 / 湿性材料如何调整

7.1 核心原则：两个维度

  1. 它会不会抢水？抢多少？ → 决定要不要加水
  2. 它会不会削弱面筋？削弱多少？ → 决定要不要降水量或补强工艺

7.2 干性材料

材料建议用量

核桃/榛子等坚果10–15%-3~-5%（高脂降低需水感知）油脂削弱面筋、减缓发酵，膨胀略降先 160℃ 烘 6–10 分钟去表面水分，冷却再用
亚麻籽（粉）5–10%，最多 20%每加 100% 亚麻籽加约 75% 水（10% 用量 → 水合 +8~10%）吸水极强必须提前浸泡，否则抢走面团的水

干性材料通用规则

  • 总量控制在 占粉重 20–25% 以内（坚果+果干合计），超过明显压制膨胀
  • 加入时机：第 2 或第 3 次折叠时。太早阻碍面筋形成并沉底，太晚会在整形时被割出来
  • 手法：撒在面团表面，靠折叠裹入，或做一次 lamination。不要用力揉

7.3 湿性材料

材料替换方式换算与调整
鸡蛋最多替换总水量 20–30%蛋液重量 × 0.7 = 等效水量（蛋约 30% 是固体）。例：50 g 蛋液 ≈ 35 g 水
牛奶可 1:1 替换水约 87–88% 是水；含乳糖→上色更快，含脂肪→面筋略弱
黄油5–20% 占粉重后加。每加 10% 黄油可减水 3~5%；黄油越多发酵越慢

湿性材料通用规则

  • 新增液体重量直接计入总水重，再回头核对水合率是否在粉能承受的范围
  • 一次只改一个变量：要么改水合，要么换粉，不同时动
  • 加了糖/油/奶后发酵会变慢：一发涨幅目标从 50–70% 略降到 40–60%，靠状态判断而非钟表

八、知识点总结

8.1 面粉：看三个指标，不止蛋白

指标意义你的配方对应
蛋白质含量"有多少蛋白"，决定潜在筋力纯芯 11.9%，混合后有效成筋蛋白 ≈10.7%
W 值（面筋强度）"蛋白有多强"，决定能扛多高水合/多长发酵纯芯属中弱区间，不支撑 85%
P/L（延展性平衡）弹性 vs 延展性的平衡，0.5 最理想太低会摊，太高会回缩
灰分矿物质含量，决定风味与颜色0.37% = 极精制、低风味、低酶

结论：蛋白含量不是唯一指标。同样标 13% 的粉，在高水合酸种里表现可能完全不同。

8.2 温度：Q10 是理解发酵的钥匙

  • 酵母活性 Q10 ≈ 2.2：温度每升 10℃，活性约翻倍；每降 10℃，约减半
  • 4℃ 的发酵速率 ≈ 24℃ 的 1/5
  • 出缸面温目标 22–24℃，用 DDT 公式反推水温：
    水温 = 4×目标面温 − (室温 + 粉温 + 种温 + 摩擦系数)
  • 立式机中速 5 分钟摩擦约 +4–6℃

8.3 发酵：看状态，别看时间

项目参考
一发涨幅24℃ 目标 +50–70%；温度越高越早收手
一发时长24℃、10% 种粉比，约 4–5 小时
最客观工具小样瓶法（取 30 g 装小瓶记高度）
指压测试缓慢回弹留浅痕 = 刚好；快速回弹 = 不足；塌陷不回 = 过度
冷藏二发4℃，10–14 小时；必须严密覆盖防结皮

关键认知：低温不"暂停"发酵，只是减慢。所以"一发 12 小时"这种名义时长没有意义——衡量的是等效发酵量，不是钟表时间。

8.4 折叠：数量、时机、温度

  • 高水合（80%+）需要 4–6 次折叠，间隔 30–40 分钟
  • 覆盖发酵前 3–4 小时，不要全挤在开头
  • 绝不要折叠冷面团：冷面团面筋硬化，折叠等于撕裂；且冷面团不产气，压垮的气室无法重建
  • 更高水合可用 coil fold（卷折）代替普通折叠，撕裂更小

8.5 蒸汽：4–6 秒，别更多

  • Hamelman《Bread》第 3 版：入炉前后各注入一次，总体 4–6 秒是合适量
  • 蒸汽计量单位是总注入秒数，靠关风门把湿气留在炉内
  • 作用：延缓表皮定型 → 提升入炉急胀；让表皮糊化有光泽；促进酶解产生上色
  • 过度蒸汽的后果：扁平、厚韧皮、割口不翻
  • 略发过头的面团反而应少给蒸汽，让表皮更快结皮防摊平

8.6 烘烤：用温度计，不用眼看

面包类型中心目标温度
酸种乡村面包96–99℃（205–210℉）
带馅/含脂吐司88–93℃
贝果/小餐包88–93℃
  • 核心温度到 91–93℃ 时面筋才完全凝固定型；高水合酸种需要更高
  • 面包变棕比中心熟透快得多——看颜色会误判
  • 出炉后 1.5–2 小时再切，否则组织会被压塌、显得发黏

8.7 淀粉酶攻击（starch attack）

  • α-淀粉酶在淀粉糊化温度区间活性最高，会把已糊化的淀粉切成糊精
  • 糊精化不可逆，出炉后再烤也救不回来 → 组织发亮、发黏、按压回粘
  • 黑麦风险更高：α-淀粉酶含量高、耐热，且黑麦淀粉糊化温度更低（50–60℃ 起）
  • 解法是酸：酸种产生的乳酸/醋酸降低 pH 抑制 α-淀粉酶——这是传统黑麦面包必须用酸种的结构性原因，不是风味偏好
  • 黑麦的戊聚糖含量 6–9%（小麦仅 2–3%），抢水且包裹面筋阻碍交联 → 加黑麦必须减水或补强工艺

8.8 盐的三个作用

  1. 风味：面包的骨架味道
  2. 收紧面筋：提升持气性和面团强度
  3. 抑制蛋白酶：保护面筋不在长发酵中被分解

用量：1.8–2.2%；长发酵 + 黑麦建议 2.0%。水合阶段就加。

8.9 添加物的两个维度

  • 抢水吗？抢水 → 加水（亚麻籽、可可粉、全麦粉）；带水/带油 → 减水（果干、油脂）
  • 削弱面筋吗？会 → 降水量或同时补强工艺（坚果、可可脂、糖）
  • 总量控制：坚果 + 果干合计 ≤ 粉重 20–25%
  • 加入时机：第 2–3 次折叠时

一句话记忆：先算水，再算筋，最后算时机。

8.10 排查问题的固定顺序

① 酵母/酵种活性 → ② 温度（面温、环温）→ ③ 面筋（粉的强度 + 折叠）→ ④ 发酵时长与终点 → ⑤ 配方比例 → ⑥ 烘烤与冷却

按这个顺序排查，能避免"改了一堆参数却不知道是哪个起的作用"。
