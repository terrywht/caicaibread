# 菜菜面包 · 酸种欧包（caicaibread）

家庭酸种欧包（sourdough）的**实烤记录 + 发酵诊断 + 配方迭代**文档库。

这里沉淀的不是"教程"，而是**一个人和一只面包之间反复试错的全过程**：从 85% 高水合配低强度粉，到 69% 真水合配法国面包粉；从折叠冷面团，到把冷藏段正确地放到二发；从"以为种活力不足"，到确认种没问题、转向读数与流程。**每次判断附依据，每处错误留痕。**

## 当前配方基准（更新至 2026-10-04 实炉）

| 项目 | 数值 |
|---|---|
| 主面团粉 | 铁塔法印 90%（450 g）+ 黑麦 10%（50 g）= 500 g |
| 鲁邦种 | 100 g（100% 水合，占总粉 18.2%） |
| 补加水 | 330 g |
| 盐 | 11 g（占总粉 2.0%）——10-04 炉起生效 |
| **总粉 / 总水** | 550 g / 380 g |
| **真水合率** | **69.1%**（水 ÷ 粉；铁塔法印工作区间 68–75% 的中段） |
| 单只生重 | 470 g × 2 |
| 出缸面温 | 23.8℃（目标 23–26℃） |
| 室温 / 冷藏 | 24℃ / 4℃（10-04 炉冰箱实测 6.5℃） |
| 折叠 | 3 次，间隔 40 min |
| 一发 | 6.5 h；**末次折叠后长静置（10-04 实测 4.5 h）直到整形** |
| 二发 | 整形后冷藏 12 h（6.5℃）；取出不回温，直接割、直接烤 |
| 烘烤 | 300℃ / 蒸汽 5 秒 / 5 min → 上 250 下 270 / 15 min → 上 250 下 230 开风门 / 3 min，共 21–23 min；**中心温度目标 96–99℃（10-04 实测 98℃）** |

**面粉**：鸟越铁塔法印——法国面包专用粉，粗蛋白 11.9%、灰分 0.44%（多数渠道；另有 0.37% 说法）、W ≈ 200、P/L 0.7。选它的理由不是蛋白高（11.9% 其实偏低），而是**灰分高带来的延展性、风味与酶活性**。

## 下一炉改动清单（10-04 炉之后：只改 3 件，配方不动）

10-04 炉已验证「配方没问题、问题在工艺」——配方侧只改了盐一项，耳朵就立起来了。所以这一轮**固定跑通的部分，只修剪枝节**。

1. **折叠加到 4 次**，排法 `40 / 80 / 120 / 160 分钟`，末次后仍保留长静置到整形（保留已跑通的 4.5 h）—— 对应"中部偏大气孔"
2. **下火 270 → 245℃ + 烤盘上移一层 + 入篮前抖掉底部浮粉** —— 对应"底部焦黑带"
3. **撒粉减半 + 改用粘米粉 + 顶面不撒** —— 对应"表皮浮粉偏厚"

**配方继续不动**：鲁邦种保持 100 g。6.5 h 一发 + 长静置已经跑通，没必要加种。

**下次请补充记录**：① 烤到 12–15 分钟掉头一次；② 出炉后 4–6 小时再切；③ 两只分别记录耳朵/上色与炉内位置（判断是否有热点）；④ **留小样瓶**（6.5 h 涨到多少，是判断一发是否到位的唯一量化依据）；⑤ 沿垂直方向再切一刀。

> **一次只改一个变量**的原则在"主线刚突破"时要让位于"固定基线"——先让跑通的组合重复一次，再动新的。

## 仍未定位的问题

**一发 5 h / 24℃ 只涨 +25%（小样瓶读数）**，候选按可能性排序：

1. 小样瓶读数可靠性（同时给出 1.25× 和 1.5×，差 20 个百分点）
2. 折叠节奏干扰读数（末次折叠距整形仅 1 h，此刻是从"折叠后体积低点"重新膨起）
3. 种与面团混匀不足
4. 接种量 18.2% 偏低
5. 69% 低水合"体积涨幅天然保守"

## 已排除的方向（不要重复怀疑）

| 排除项 | 依据 |
|---|---|
| 出缸面温偏低 | 实测 23.8℃，目标区间 23–26℃ |
| 鲁邦种活力不足 | 1:1:1 喂养、2 h 涨到 2 倍，高活性 |
| 冷藏水合削弱面筋 | 冷藏 4℃ 操作，酶活性极低 |
| 蒸汽 5 秒不足 | Hamelman 第 3 版标准即"总注入量 4–6 秒" |
| 切太早导致压塌 | 出炉 6 h 才切 |
| 二发偏过导致开口宽 | 一发 +25% + 冷藏仅 9 h，两项同向指向欠发 |

本库内容由家庭烘焙者与 AI 面包发酵诊断师协作产出，**大量结论带有明确的可信度标注**：

- 实测 / 机制直接的推论 / 经验规律 / 推测 —— 文档中逐条区分
- 图片识别结论一律附"仅供参考，以实际面团状态为准"
- **我犯过的判断错误全部保留在案**，不删改，以"撤回项"形式对照呈现

烘焙受温度、湿度、面粉批次、酵种状态、烤箱性能多重影响。这里的每一条都是**在特定条件下得出的**，请以自己面团的真实状态为准。
