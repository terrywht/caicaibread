## 酸种欧包配方优化与知识手册（第三轮，输出文档）

用户在前两轮诊断基础上提出 5 个问题：①优化配方与流程 ②推荐具体品牌面粉 ③追问"85% 水合配 13%+ 粉"依据及适用性 ④加干性/湿性材料如何调整 ⑤总结全部知识点。

**关键产出**：

1. **配方方案**（两条路）：
   - 方案 A（推荐）：90% 高筋粉（蛋白 13%+）+ 10% 黑麦、补加水 70% + 鲁邦种含水 10% = 总水合 80%、鲁邦种 20%、盐 2.0%
   - 方案 B（进阶）：同上但补加水 80%，总水合 85%
   - 1kg 粉配方：高筋粉 450g + 黑麦 50g + 鲁邦种 200g + 盐 20g + 补加水 350g = 1070g
   - 500g 面团：高筋粉 210g + 黑麦 23g + 鲁邦种 93g + 盐 9.3g + 补加水 163g

2. **流程核心改动**：盐改为水合阶段加入（抑制 protease）；水合冷藏 2–4h；一发改连续 24℃ 暖温 4–5 小时；折叠 4–6 次全部在室温下（绝不动冷面团）；一发终点用**小样瓶法（aliquot jar）**判断 +50–70%；冷藏二发 10–14h 严密覆盖；保留原蒸汽 5 秒与烘烤曲线，增加中心温度 ≥96℃ 判据。

3. **面粉推荐**：王后日式吐司粉（13.8–14.1%/0.42%）、昭和先锋（14.0%/0.42%）、金像面包粉（13.7%）、王后柔风吐司粉（13.2%）；T 系列路线：王后 T65（10.5%/0.65%）、日清百合花（10.7%/0.45%）。依据为蛋白含量、灰分、吸水率实测（王后日式吐司粉可达 80%）、产地工艺。

4. **"85% 配 13%+ 粉"溯源**：从①蛋白↔吸水率正相关 ②高水合需面筋强度支撑 ③行业实践三条链推导；**不是硬性规定**。四种反例：法棍/T65（低蛋白靠高灰分+高延展性）、全麦黑麦（吸水高但成筋弱）、可颂（故意要弱面筋）、馒头。更准确框架：水合上限 = f(W 值、P/L、工艺强度、目标组织)，**W 值比蛋白百分比更关键**（85% 需 W 280–350）。

5. **添加物规则**：两维度（抢水？削弱面筋？）。坚果 10–15% 且 -3~-5% 水；亚麻籽每 100% 加 75% 水；果干 15–25% 且 -3~-5% 水；可可粉 +5~+8% 水；坚果+果干合计 ≤ 粉重 20–25%；加入时机为第 2–3 次折叠。湿性：蛋液 ×0.7 = 等效水量；黄油每 10% 减水 3~5%；糖/油/奶会减慢发酵。

## 第四轮：鸟越铁塔法印 vs 韩国白雪牌对比 + 铁塔法印版配方文档

**用户问题**：手头有鸟越铁塔法印与韩国白雪牌高筋粉，哪款更适合？以更适合的粉为基础出配方流程，并整合知识点输出可打印文档。

**面粉核实结果**：
- 鸟越铁塔法印：蛋白 11.9%、**灰分 0.37%（甘單手作） vs 0.44%（橙品/全國食材/瑪德蓮/宜得食，多数）**、法国面包专用粉、日本广岛县制造、加拿大春麦+九州小麦+美麦拼配、W 约 200、P/L 0.7。淘宝百科称湿面筋 13.2%、灰分 0.42%、淀粉损伤率 ≤3.5%（非官方，可信度中等）
- CJ 白雪 高筋粉：韩国产、美国/加拿大小麦、零售主力粉。蛋白：japanesenkoreanmart 标 10–12g；Open Food Facts 标 13g；Pandough 标 12%（估算）。**灰分与 W 值均无官方数据**。Pandough 评估 W 205–300（估算）、**水合 58–65%**，明确提示"Mid-strength rather than extra-strong, so keep very long cold proofs and 75%+ hydration for stronger flours"

**判定结论**：铁塔法印更适合。理由不在于蛋白（11.9% 甚至低于纯芯），而在于 **灰分更高（0.37%→0.44%）带来三重优势**：①延展性更好（P/L 更接近理想）②麦香与上色更强 ③酶活性更活跃。定位为法国面包专用粉，直接对应欧包。白雪牌定位是通用吐司/披萨粉，水合上限低。

**配方重算（方案 A）**：
- 水合 **85% → 76%**（关键判断：铁塔法印有效成筋蛋白 11.9%×90% ≈ 10.7%，W≈200，撑不住 85%）
- 盐 **1.6% → 2.0%**
- 鲁邦种 **30% → 20%**
- 黑麦维持 10%
- 烘焙百分比：铁塔法印 90% + 黑麦 10% = 100%，鲁邦种 20%（含粉 10%、含水 10%），盐 2.0%，补加水 66%
- 单个 500g 面团：**铁塔法印 239g + 黑麦 27g + 鲁邦种 53g + 盐 5.3g + 补加水 176g = 500g**
- 1kg 粉：铁塔法印 900g + 黑麦 100g + 鲁邦种 200g + 盐 20g + 补加水 660g = 1880g
- 方案 B（进阶）80% 水合：补加水 200g（500g 面团）
- 方案 C（传统法式）70–72%：黑麦可降至 5%
- 白雪牌临时替换版：水合降至 70%（补加水 146g）、一发缩短至 3–4h

**新增知识点**：有盐 autolyse 是矛盾术语（Hamelman 定义 autolyse 为粉+水不含盐）；6.9 节；排查问题六步判据表；一页执行清单（配方/时间线/烘烤）
